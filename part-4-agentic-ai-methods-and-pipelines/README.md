# Part 4 (Optional) — Agentic AI Methods and Pipelines

> **Optional**, self-paced. Modules 17–25. Requires the course WRDS class account.

Module 17 builds this part's own panel on WRDS — Compustat fundamentals joined to the 10-K MD&A text of the same firm-years — and Modules 18–23 apply one method per module to it, with the agent doing the implementation. Modules 24–25 raise the level of autonomy: first directing an agent through an entire analysis you specify, then surveying agents that choose the research question themselves. Run this alongside Part 3, not after it: the WRDS class account expires at the end of term.
